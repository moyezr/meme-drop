Scoring rubric

Post fit: 1 unrelated or wrong target; 3 plausible but generic; 5 specific and socially appropriate. Comic turn: 1 none; 3 mildly amusing; 5 a clear, fresh joke. Template fit: 1 fights the image; 3 works; 5 uses its visual grammar. Readability: 1 broken or unreadable; 3 readable with friction; 5 immediately legible.

Rate each suggestion 1–5 and answer whether you would use it. Judge the source independently: a reply fits, abstain, or more context is needed. Leave uncertain items unscored. Empty results and failures still need a source judgment. Related case variants are not independent observations.
